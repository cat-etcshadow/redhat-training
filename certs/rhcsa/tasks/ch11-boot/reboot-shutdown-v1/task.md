## Schedule and Cancel a System Shutdown

Your task:

1. Schedule the system to reboot in 10 minutes using the `shutdown` command,
   with the broadcast message `Maintenance restart`.
2. Confirm the reboot is scheduled.
3. Cancel the scheduled reboot before it takes effect.
4. When you are finished, the system must have **no pending shutdown or
   reboot scheduled**, and must **not have actually rebooted**.
