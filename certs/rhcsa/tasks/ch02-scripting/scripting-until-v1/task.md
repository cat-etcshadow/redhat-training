## Write a script using an until loop to poll for a file

Create an executable script at **{{SCRIPT_PATH}}** that waits for a file to appear. It must accept one argument, the path to the file to wait for — printing usage to stderr and exiting non-zero if none is provided — and use an until loop to repeatedly check whether the file exists, sleeping 1 second between checks and printing a progress line each attempt (e.g. `Waiting... (<attempt>/<max>)`). After **5** attempts without success, it must print an error containing the word "Timeout" to stderr and exit non-zero; as soon as the file appears, it must print a line containing the word "found" and exit **0**.
