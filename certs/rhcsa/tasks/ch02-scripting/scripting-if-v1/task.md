## Write a script with if/elif/else

Create an executable shell script at **{{SCRIPT_PATH}}** that accepts exactly one argument, a username; if none is given, print `Usage: check_user.sh <username>` to stderr and exit **1**. If the user exists on the system, print `User <name> exists with UID <uid>` and exit **0**; if the user does not exist, print `User <name> does not exist` and exit **2**.
