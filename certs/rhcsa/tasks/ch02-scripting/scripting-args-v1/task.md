## Write a script that validates positional arguments ($1, $2, $#)

Create an executable script at **{{SCRIPT_PATH}}** that backs up a file. It must accept exactly two arguments, `<source-file>` and `<destination-directory>`; if the wrong number of arguments is given, print `Usage: backup_file.sh <source-file> <destination-dir>` to stderr and exit **1**. If `<source-file>` does not exist or is not a regular file, print an error to stderr and exit **2**. Create `<destination-directory>` if it does not exist, then copy `<source-file>` into it with a timestamp suffix in the form `<original-name>.<YYYYMMDD-HHMMSS>`, print `Backed up <source> to <destination-path>`, and exit **0** on success.
