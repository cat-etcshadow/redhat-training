## Write a script that loops over files (command substitution)

Create an executable script at **{{SCRIPT_PATH}}** that accepts two arguments, `<log-directory>` and `<archive-directory>`, exiting **1** with a usage message if the count is not exactly 2. It must create the archive directory if it does not exist, then use command substitution to loop over every `.log` file in the log directory (non-recursive) and compress each one with `gzip`, saving the compressed file in the archive directory. If no `.log` files are found, print `No log files found in <dir>` and exit **0**; exit **0** on success.
