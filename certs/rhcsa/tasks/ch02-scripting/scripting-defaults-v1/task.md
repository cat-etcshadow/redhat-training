## Write a script using parameter-expansion defaults and string tests

Create an executable script at **{{SCRIPT_PATH}}** that prints a deployment summary. Using parameter expansion (not a separate `if` check), it must default the **APP_ENV** environment variable to `development` when unset or empty, and default its first positional argument, the deployment target, to `localhost` when not provided. Using a string comparison test, it must verify **APP_ENV** is one of `production`, `staging`, or `development`, printing an error to stderr and exiting non-zero if it is none of these, and on success print exactly `Deploying to <target> in <env> mode` and exit **0**.
