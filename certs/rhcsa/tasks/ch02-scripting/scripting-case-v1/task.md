## Write a script using a case statement

Create an executable script at **{{SCRIPT_PATH}}** that acts as a simple service controller wrapper. It must accept exactly two arguments, `<action>` and `<service-name>` — printing usage to stderr and exiting **1** if the count is wrong — and use a `case` statement on `<action>`: `start` runs `systemctl start <service>` and prints `Starting <service>`; `stop` runs `systemctl stop <service>` and prints `Stopping <service>`; `restart` runs `systemctl restart <service>` and prints `Restarting <service>`; `status` runs `systemctl status <service>` and lets its output pass through; `enable` runs `systemctl enable --now <service>` and prints `Enabling <service>`; any other action prints `Unknown action: <action>` to stderr and exits **3**. The script's exit code must propagate from the underlying `systemctl` command, and it exits **0** on success.
