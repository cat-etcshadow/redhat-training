## Create a cron job for a specific user

The user **{{CRON_USER}}** (already exists) must run a script automatically. The script `{{CRON_SCRIPT}}` already exists and is executable. Create a cron job that runs as the user **{{CRON_USER}}**, not as root, running `{{CRON_SCRIPT}}` every day at **{{CRON_HOUR}}:{{CRON_MIN}}**.
