## Extract a single file from a tar archive

The archive **{{ARCHIVE}}** contains a full project tree with several files and subdirectories, and must remain untouched. Extract only **{{TARGET_FILE}}** from **{{ARCHIVE}}**, placing it under **{{EXTRACT_DIR}}** with its directory structure preserved (e.g. producing `{{EXTRACT_DIR}}/{{TARGET_FILE}}`), without extracting the rest of the archive's contents.
