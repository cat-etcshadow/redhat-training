## Add a secondary IPv4 address to an existing connection

Your task:

1. Identify the active NetworkManager connection on the primary network
   interface.
2. Add **{{SECONDARY_IP}}** as an **additional** IPv4 address on that
   connection, without removing its existing address.
3. Apply the change.
4. The interface must end up with both its original address and
   **{{SECONDARY_IP}}**.
