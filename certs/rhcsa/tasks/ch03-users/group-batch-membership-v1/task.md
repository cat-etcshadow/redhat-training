## Replace a group's entire membership list in one command

The group **{{TARGET_GROUP}}** exists and currently has one member, **{{OLD_MEMBER}}**. The users **{{NEW_MEMBER1}}**, **{{NEW_MEMBER2}}**, and **{{NEW_MEMBER3}}** already exist but are not members of the group. Using a single command, set the membership of **{{TARGET_GROUP}}** to be exactly **{{NEW_MEMBER1}}**, **{{NEW_MEMBER2}}**, and **{{NEW_MEMBER3}}**, replacing the existing membership list entirely so that **{{OLD_MEMBER}}** is no longer a member.
