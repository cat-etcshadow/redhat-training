## Manage group membership

Create user **{{TARGET_USER}}** if it does not already exist, and create supplementary groups **{{SUPP_GROUP1}}** and **{{SUPP_GROUP2}}** and group **{{NEW_PRIMARY}}** if they do not exist. Change **{{TARGET_USER}}'s** primary group to **{{NEW_PRIMARY}}**, and add **{{TARGET_USER}}** as a supplementary member of **{{SUPP_GROUP1}}** and **{{SUPP_GROUP2}}** without removing any supplementary groups **{{TARGET_USER}}** already belongs to.
