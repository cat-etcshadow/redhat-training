## Create users with password aging and group constraints

On **server**, create a group named **{{GROUP}}** with GID **{{GID}}**. Create user **{{USER1}}** with UID **{{UID1}}**, password **{{PASSWORD}}**, as a supplementary member of **{{GROUP}}**, with password aging configured so the password must be changed every **{{MAX_AGE}}** days, the user is warned **{{WARN_DAYS}}** days before expiry, and the account is locked **{{INACTIVE}}** days after the password expires without being changed. Create user **{{USER2}}** with UID **{{UID2}}**, password **{{PASSWORD}}**, as a supplementary member of **{{GROUP}}**, login shell **/bin/sh**, and locked so it cannot log in interactively using a password. All settings must survive a reboot.
