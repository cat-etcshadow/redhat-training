## Configure Flatpak Repository Access and Manage Applications

The system does not currently have any Flatpak remotes configured. Ensure the `flatpak` package is installed, add the Flathub repository as a system-wide remote named `flathub` using the repo file at `https://dl.flathub.org/repo/flathub.flatpakrepo`, and install the application `org.gnome.gedit` from that remote, system-wide. The application `org.gnome.Calculator`, which is already installed, must be removed.
