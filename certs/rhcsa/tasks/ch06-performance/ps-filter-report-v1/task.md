## Filter processes by name with ps and save a PID report

Two worker processes, **rhtr-worker-a** and **rhtr-worker-b**, are running. A third, unrelated process, **rhtr-other-proc**, is also running and must be excluded. Write the PIDs of every process whose command line contains **rhtr-worker**, one per line and sorted numerically, to **{{REPORT_FILE}}** — and nothing else.
