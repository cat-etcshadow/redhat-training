## Clone a Playbook Repository and Commit a New File

A shared playbook repository exists at **{{BARE_REPO}}** (a bare git
repository) on the control node.

Your task:

1. Clone it to **{{CLONE_DIR}}**.
2. Inside the clone, create a new file named **{{NEW_FILE}}** containing any
   valid YAML playbook content.
3. Stage and commit the new file with a commit message.
4. Push the commit back to the `origin` remote (the bare repository at
   **{{BARE_REPO}}**).
